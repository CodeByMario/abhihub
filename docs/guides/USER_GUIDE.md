## Getting Started

### What is AbhiHub?

AbhiHub is a student-driven academic resource hub that provides:

- 📚 **Study Notes** — Subject-wise notes curated by contributors
- 📝 **Previous Year Questions (PYQs)** — Real exam papers organized by year
- 🔬 **Practical & Lab Guides** — Step-by-step lab manuals
- 👥 **Community Contributions** — Share and access peer-verified resources

### System Requirements

- **Browser**: Chrome, Firefox, Safari, or Edge (latest versions)
- **Internet**: Stable internet connection for first-time access
- **Device**: Works on desktop, tablet, and mobile devices

## Creating an Account

### Sign Up

1. Visit the AbhiHub homepage
2. Click **"Create Account"** or **"Sign Up"**
3. Choose your sign-up method:
   - **Email & Password**: Enter your email and create a secure password
   - **Google Account**: Click "Continue with Google" for quick sign-up
4. Complete the verification process if required
5. You're in! You'll be redirected to the dashboard

### Log In

1. Click **"Log In"** from the homepage
2. Enter your credentials or use Google sign-in
3. Access your personalized dashboard

### Password Recovery

1. On the login page, click **"Forgot Password?"**
2. Enter your registered email address
3. Check your inbox for a password reset link
4. Follow the link to create a new password

## Using Search

AbhiHub features a powerful **Smart Search** system with advanced filtering.

### Basic Search

1. Find the search bar on the dashboard
2. Type keywords like subject name, topic, or resource type
3. Press Enter or click the search icon
4. Browse through the filtered results

### Advanced Search Syntax

Use these filters for precise results:

| Filter | Example | Description |
|--------|---------|-------------|
| `type:` | `type:notes` | Filter by resource type |
| `subject:` | `subject:dbms` | Filter by subject name |
| `author:` | `author:john` | Filter by contributor |
| `year:` | `year:2024` | Filter by year |
| `exam:` | `exam:midsem` | Filter by exam type |

**Combined Example:**
```
dbms type:notes year:2024
```
This searches for DBMS notes from 2024.

### Search Tips

- **Abbreviations work**: `pyq` → Previous Year Questions, `prac` → Practicals
- **Fuzzy matching**: Slight misspellings are auto-corrected
- **Synonyms recognized**: `imp` → `important`, `paper` → `pyq`

## Contributing Resources

Help the community by sharing your study materials!

### Upload Process

1. Navigate to **Upload** from the main menu
2. Fill in the required details:
   - **Subject** — Select or enter the subject
   - **Year** — Academic year
   - **Type** — Notes, Papers, Practical, etc.
   - **Unit/Practical Name** — Specific unit or practical number
3. Click **"Choose File"** and select your document (PDF recommended)
4. Click **"Upload"** to submit

### Contribution Guidelines

✅ **Do's:**
- Upload clear, readable documents
- Provide accurate subject and topic information
- Share original or properly attributed content
- Use descriptive file names

❌ **Don'ts:**
- Upload copyrighted materials without permission
- Share incomplete or incorrect information
- Submit duplicate files already on the platform

### After Upload

- Your contribution will be reviewed for quality
- Once verified, it appears for other users
- Contributors receive attribution on their files

## Installing as an App (PWA)

AbhiHub works as a **Progressive Web App** — install it on your device for quick access!

### On Chrome (Desktop)

1. Visit AbhiHub in Chrome
2. Look for the install icon (➕) in the address bar
3. Click **"Install"**
4. Access AbhiHub from your desktop like a native app

### On Android

1. Open AbhiHub in Chrome
2. Tap the **three-dot menu** (⋮)
3. Select **"Add to Home Screen"** or **"Install App"**
4. Confirm and find AbhiHub on your home screen

### On iOS (Safari)

1. Open AbhiHub in Safari
2. Tap the **Share button** (↑)
3. Scroll and tap **"Add to Home Screen"**
4. Confirm the name and tap **"Add"**

### Benefits of Installing

- 🚀 **Faster loading** from home screen
- 📴 **Offline access** to cached resources
- 📱 **App-like experience** without app store
- 🔔 **Stay updated** with latest resources

## Troubleshooting

### Common Issues

| Problem | Solution |
|---------|----------|
| Can't log in | Check credentials, try password reset |
| Files not loading | Refresh page, check internet connection |
| Search returns no results | Try different keywords, check spelling |
| Upload fails | Ensure file is PDF and under size limit |
| PWA install not showing | Use Chrome, clear cache, try again |

### Offline Mode

If you lose internet connection:
- Previously viewed resources may still be accessible
- An offline notification banner will appear
- Full functionality resumes when back online

### Clear Cache

If experiencing issues:
1. Open browser settings
2. Navigate to Privacy/History
3. Clear cached images and files
4. Reload AbhiHub
