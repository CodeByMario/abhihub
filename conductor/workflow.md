# Development Workflow

## Principles
- **Ponytail Coding Philosophy**: Keep solutions minimal, concise, and focused. Prefer standard library over external dependencies.
- **Spec-Driven Execution**: Plan -> Spec -> Implement -> Verify -> Review.
- **Zero Token Waste**: Concise commits, diff-style changes, no unneeded refactoring.
- **Strict Data Privacy**: No raw tokens, emails, passwords, or PII in logs or analytics payloads.
